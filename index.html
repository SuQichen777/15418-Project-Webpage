Parallel GPU Hash Tables: Thread Cooperation, Memory Access, and Contention

Jiaxi Zhang (jiaxizha) & Hongzheng Li (hongzhel)

ProposalPDF Milestonedue Nov 23 Final reportdue Dec 10 PosterDec 11

Summary

We will implement and optimize a concurrent hash table in CUDA that supports parallel insertion, look-up, and potentially deletion or supporting dynamic size. We will explore how collision handling, atomic operations, and GPU memory access patterns affect performance. We will evaluate throughput against CPU and baseline GPU implementations across different table sizes, load factors and key distributions.

Platform
Multicore CPU host and CUDA-capable NVIDIA GPU on GHC
Languages / APIs
C++/CUDA; CUDA atomic operations and cooperative-group primitives
Main goal
60% of NVIDIA cuCollections’ performance under the same configuration
